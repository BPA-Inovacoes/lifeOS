## Implementado

| Item | Detalhe |
|------|---------|
| **Focus trap** | `useFocusTrap` em `AppModal` (paleta, atalhos, confirmações) |
| **Modais** | `role="dialog"`, `aria-modal`, labels/-labelledby |
| **Teclado** | ⌘K, `?`, Esc, ↑↓ Enter na paleta |
| **Contraste** | Tema escuro zinc + emerald — texto principal ≥ zinc-200 |
| **Inputs data** | Classe `lifeos-date-input` com indicador visível |

## Verificação manual recomendada

1. Tab apenas dentro do modal aberto (sem fugir para o fundo).
2. Leitor de ecrã anuncia título do modal e botão fechar.
3. Estados de erro (`QueryErrorPanel`) legíveis (não só cor).
